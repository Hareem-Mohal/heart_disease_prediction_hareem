# Heart Disease Prediction System (AIC354 - Assignment 2)

End-to-end ML system on the UCI Heart Disease (Cleveland) dataset using 4 input attributes:
**Age, Sex, Chest Pain type, Max Heart Rate**. Model: Support Vector Classifier (SVC).

**Live demo:** https://YOUR-APP-NAME.streamlit.app

## Files
- `Heart_Disease_Prediction.ipynb` - full notebook (data collection -> deployment)
- `processed.cleveland.data` - UCI dataset
- `heart_svc_trained_model.pkl`, `heart_scaler.pkl` - trained model and scaler
- `app.py` - Streamlit web app
- `requirements.txt` - packages for deployment; `requirements-notebook.txt` - packages for the notebook
